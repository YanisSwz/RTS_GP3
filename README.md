# RTS AI

This is a school project aiming to implement a multi-layered RTS AI in Unity using various AI techniques. We were 2 and had 2 weeks.

## ℹ️ Practical informations

Launch LargeBattlefield in the editor.

## ⌨️ Controls

| Key | Action |
| :---: | :---: |
| Move | WASD/ZQSD |
| Select (Units and UI) | left click |
| Give order (move, capture, attack, repair) | right click |


## ⚙️ Techniques

We used Utility for goals, Desicion trees for squads and FSMs for individual units.
